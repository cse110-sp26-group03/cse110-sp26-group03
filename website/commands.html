Commands

All commands start with mt. Expand a section for usage and examples.

mt version

Prints the installed Manta version from package.json. No flags or arguments.

mt version
# 1.2.0
mt create

Creates a new issue. Title is required (positional or --title).

mt create "My new issue" --desc "Needs to be solved" --priority p1 --assignee bob

Optional flags: --desc, --status, --priority, --type, --assignee. See Reference.

mt update

Updates one or more fields on an existing issue. At least one field flag is required besides the ID.

mt update manta-h3kp --title "Changed the title" --status in_progress
mt view

Lists issues or shows one issue in detail. Uses an alternate terminal screen when run in a TTY; press ESC to return to your shell.

  • List: mt view — paginated table; use left/right arrows to change pages.
  • Detail: mt view manta-h3kp — short IDs work (e.g. mt view h3kp).
  • Filters: mt view --priority p1, mt view --all, mt view --cb alice
mt view
mt view manta-h3kp
mt view --priority p1 --all
mt view --createdBy alice

--createdBy (alias --cb) is view-only — it filters the list by who created the issue.

After git pull: mt view reads the SQLite cache only. Run mt sync (or any write command) first if the list may be stale.
mt sync

Rebuilds the local SQLite cache from .manta/manta.jsonl. No arguments or flags.

mt sync
# Synced successfully.

Use after git pull when teammates’ issues arrived in the log and you want an up-to-date view without creating an issue.

mt close

Marks an issue as closed (updates status only).

mt close manta-h3kp
mt delete

Permanently removes an issue. You will be asked to confirm (y/n).

mt delete manta-h3kp

Field and flag details: Reference
