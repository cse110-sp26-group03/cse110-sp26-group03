Reference

Fields you can set, flags you can pass, and metadata assigned automatically.

Issue IDs

IDs look like manta-h3kp — the suffix is four random Crockford base32 characters (lowercase). You can often use just the suffix with mt view or update commands.

Editable fields

Field Flags Notes
title --title, -t Required on create; max 50 characters
description --desc, -d Max 512 characters
status --status, -s open, in_progress, closed
priority --priority, -p p0–p9; p0 is highest (default often p5)
issue type --type bug, feature, task, docs, store
assignee --assignee, -a Letters a-z and A-Z only

Quotes around values are optional: --title "hello" and --title hello are equivalent.

View-only flags

Flag Alias Used with
--createdBy --cb mt view only — filters list by creator
--all — mt view — include closed issues in the list

Passing --createdBy to create, update, close, or delete is rejected. You cannot set createdBy manually; it is assigned at creation time.

Auto-assigned fields

Field Description
ID Assigned on create; cannot change
createdAt ISO timestamp (UTC) at creation
createdBy OS username at creation; filter with mt view --cb <name>
updatedAt ISO timestamp of the most recent edit
updatedBy OS username of the most recent editor
