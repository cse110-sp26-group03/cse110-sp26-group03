# Manta

Local-first issue tracker for the terminal — by [StringRays](admin/team.md).

**User guide:** [cse110-sp26-group03.github.io/cse110-sp26-group03](https://cse110-sp26-group03.github.io/cse110-sp26-group03/) (install, commands, reference)

**Install:** [npm: manta-it](https://www.npmjs.com/package/manta-it)

```bash
bun install -g manta-it
mt version
```

**Quick try:** `mt create "My issue" --priority p1` → `mt view`

**Agile status video:** [YouTube](https://www.youtube.com/watch?v=EK99ER9aCGg)
